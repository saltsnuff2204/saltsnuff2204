## How I approach a task

1. Clarify the user scenario and expected result.
2. Reproduce the issue or define acceptance criteria.
3. Check UI, API, data, and edge cases relevant to the change.
4. Describe findings clearly enough for the team to act on them.
5. Retest the implemented change and report the result.
